# 题目 03 验收条目清单

结论只允许：通过 / 不通过 / 无法判定。每条必须有证据位置。
标注 ★ 的为阻断项：任一不通过即整题不通过。

## A 业务闭环

| 编号 | 条目 | 证据要求 |
| --- | --- | --- |
| A-1 ★ | 正常完成：发布 → 提交 → 按版本通过 → 得 10 分 → 汇总达标数 +1 | 操作录屏时间点 + 数据库/接口结果 |
| A-2 ★ | 修改分支：提交 → 退回（有反馈）→ 重交 → 通过；旧版本与意见可查 | 版本列表截图 + 历史版本接口返回 |
| A-3 ★ | 逾期分支：未交 → 助教催交 → 个别补交（有原因）→ 该生通过；其他逾期学生仍被拒 | 两个学生对照的接口响应 |
| A-4 ★ | 重复请求不产生额外版本；同请求号不同内容被拒 | 重放 3 次后的版本数 + 409 响应 |
| A-5 ★ | 旧请求（过期 base_version）不覆盖新版本 | 409 响应 + 当前内容前后对比 |
| A-6 ★ | 批旧版本被拒，学生不被置为通过 | 409 `stale_version` + 状态仍待批阅 |
| A-7 ★ | 退回无反馈被拒；已通过不可再改 | 400/409 响应 |
| A-8 ★ | 首次通过只发 1 条 +10；重复批阅/重试不重复发奖 | 流水条数 + 学生总分 |
| A-9 | 提交/退回/逾期不发奖 | 流水表无对应记录 |
| A-10 | 汇总可追溯首次提交→最终结果（含退回、补交节点） | 时间线截图 |

## B 权限与隔离

| 编号 | 条目 | 证据要求 |
| --- | --- | --- |
| B-1 ★ | 身份只来自会话，改请求参数无法越权 | 篡改 `student_id` 的请求返回 403/404 |
| B-2 ★ | 助教批阅、设补交被服务端拒绝 | 403 响应（非前端隐藏） |
| B-3 ★ | 外班学生看不到作业（404，不泄露存在性） | 外班会话请求结果 |
| B-4 | 学生无法读取他人正文/反馈/积分 | 跨人请求结果 |
| B-5 | 助教可见范围符合假设 AS-07（默认不见正文） | 页面/接口返回字段 |

## C 质量门禁

| 编号 | 条目 | 证据要求 |
| --- | --- | --- |
| C-1 ★ | 单元测试语句覆盖率整体 ≥85% | `coverage.out` 原始文件 + 汇总命令输出 |
| C-2 ★ | 各核心业务包分别 ≥85% | 按包 `go tool cover -func` 输出 |
| C-3 ★ | 无违规排除（自编 DB/HTTP 代码未被排除） | 排除清单 + 覆盖率文件交叉核对 |
| C-4 ★ | `go test -race` 通过，并发用例可重复执行 | 原始日志 |
| C-5 | `gofmt -l` 为空、`go vet ./...` 通过 | 命令输出 |
| C-6 | 覆盖失败路径：边界、非法状态、重复操作、权限 | 用例清单与用例名对应 |

## 判定规则

- 任一 ★ 条目不通过 → 整题不通过，输出阻断清单。
- "无法判定"按不通过处理，直到补齐证据。
- 验收后修改业务代码 → 重新跑 C 组与受影响 A 组，不得沿用旧报告。
