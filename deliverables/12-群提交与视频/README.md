# 12 班级群提交与视频

必须产出（场景 §10）：

1. `群提交记录/`：当天在指定班级群提交的姓名、日期、题号与题名、仓库地址、PR 与发布版本、部署地址、报告索引、视频链接（截图留存）。
2. `视频.md`：讲解与效果视频链接（可访问），须学生本人讲解并演示运行效果。
3. `讲解目录.md`：带时间点的目录，把题目要求逐条指向视频位置 / 文档 / 记录。
   讲解必须覆盖：岗位与改编背景 → 需求理解 → 原型如何服务角色 → 任务拆分理由 → Agent 开发与学生审核 → 测试与缺陷 → 独立验收 → 合并与自动部署 → Agent 约束与 Skill 使用 → Git 与质量证据 → 三组完整场景效果演示（正常完成 / 修改分支 / 逾期分支）。
