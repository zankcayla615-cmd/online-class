# 02 原型设计

## 已产出（v1.0，原型阶段）

| 文件 | 说明 |
| --- | --- |
| `prototype/index.html` | 单页交互原型入口（双击即可打开，无需服务） |
| `prototype/app.css` | 样式（教学后台风格，状态徽标与错误提示可视化） |
| `prototype/app.js` | 内存状态机：发布锁、版本追加、幂等重放、批阅绑版本、补交一次性、发奖唯一、催交记录 |
| `页面状态说明.md` | 6 个页面 + 404 页的正常态/异常态、错误码触发对照、8 分钟演示脚本、与正式实现的差异清单 |

## 覆盖的角色操作

- 教师：建草稿 → 发布（生成快照）→ 批阅台按版本通过/退回 → 批准个别补交 → 班级汇总（计数/最终状态/奖励流水/时间线）
- 学生：查看要求快照 → 提交 → 更新（新版本）→ 看反馈 → 看历史版本 → 看积分
- 助教：四类清单 → 记录催交（不可批阅，越权返回 403）
- 外班学生：作业不可见（404）

## 原型自测记录（2026-11-13）

以 `node` + `vm` 加载 `app.js` 跑 23 条断言，全部通过：发布锁、幂等重放、同请求号不同内容冲突、旧请求覆盖被拒、按版本批阅、批旧版本被拒、退回必填反馈、重复通过不重复发奖、已通过不可改、逾期不可提交、补交原因必填、补交仅该生生效、补交不可重复、催交记录。

> 该自测只验证原型逻辑，不替代正式实现的单元测试与覆盖率证据（见 `08-质量证据`）。

## 演示方式

1. 打开 `prototype/index.html`
2. 按 `页面状态说明.md` 第 4 节脚本操作，教师 / 助教 / 学生 / 外班四个身份依次切换
3. 顶栏「教学时钟 +1 小时」用于制造逾期，避免长时间等待
