# 09 Git 与 PR

必须产出（场景 §8、§9）：

1. `MCP建仓记录.md`：工具名、请求与结果、时间、仓库 URL（不得用手工/CLI 记录替代）。
2. `分支说明.md`：main 为默认主分支，业务全部在 `dev/03` 提交；主分支禁止直接推送/删除/强推，需 PR + 状态检查（附规则截图或读取结果）。
3. `提交历史.md`：格式 `[类型] [版本号] [需求/Bug编号] 中文描述`；一次提交一种类型。
4. `meegle核验/`：`meegle workitem get --work-item-id <编号> --project-key r17te9` 的真实输出，feat/fix 前必须有。
5. `PR与合并.md`：PR 链接、变更说明、测试与覆盖率、验收报告索引；优先保留原始提交的合并方式。
6. `索引.md`：题号 ↔ 需求/Bug 编号 ↔ 分支 ↔ 提交 ↔ PR ↔ 验收 ↔ 部署 的对应表。
