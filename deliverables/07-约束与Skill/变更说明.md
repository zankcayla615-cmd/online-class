## 后续调整记录模板（每次调整必须填写）

```
### vX.Y（YYYY-MM-DD）
- 改了什么：
- 为什么改（遇到的具体问题，附会话/缺陷编号）：
- 影响哪些任务/阶段：
- 调整后如何重新验证（命令、用例、复跑范围）：

```

## 规则

1. 调整前先复制当前版本到 `AGENTS.md 版本/`，命名为 `vX.Y-AGENTS.md`。
2. 只允许因**遇到真实问题**调整规则，不得为迁就实现而放宽约束（例如为达标降覆盖率、为省事允许直推 main）。
3. 任何放宽类调整必须在变更说明中写明"为什么原规则不可行"，并由学生本人确认。
4. 完工后回填规则视为无效过程证据。
