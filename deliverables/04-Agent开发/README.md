## 开发原则（摘自 AGENTS.md，执行时逐条对照）

1. 业务规则只写在 `service`，handler 只负责解析与响应，store 只负责 SQL。
2. 业务代码禁止直接 `time.Now()`，统一 `clock.Now()`。
3. 业务拒绝用 4xx + 稳定错误码，不用 500。
4. 并发正确性靠状态行 `state_version` 乐观锁与唯一约束，不靠"先查再插"。
5. 每个任务完成即留：commit + 测试原始输出 + 页面/接口证据。
