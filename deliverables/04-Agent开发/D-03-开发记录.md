## 1. 实现内容

| 能力 | 实现要点 | 文件 |
| --- | --- | --- |
| 会话 | 32 字节随机标识、服务端内存表、TTL 8h、过期即失效；Cookie `HttpOnly` + `SameSite=Lax` | `internal/session/session.go` |
| 身份解析 | 只取 Cookie → 会话 → 数据库账号；请求参数/请求体中的用户编号一律忽略 | `internal/httpapi/middleware.go` |
| 未登录拦截 | API 统一 401 `unauthenticated`；页面跳转 `/login` | 同上 |
| 授权规则 | `Allow(role, action, sameClass, isSelf)` 纯函数，6 类动作 × 4 角色 | `internal/httpapi/authz.go` |
| 班级隔离 | 作业/学生查询先校验同班；**跨班与不存在都返回 404**，不泄露存在性 | `internal/httpapi/api.go` |
| 草稿可见性 | 草稿仅本班教师可见，学生/助教按"不存在"处理 | 同上 |
| 登录/退出 | 登录失败统一提示"账号或口令不正确"（避免枚举账号）；退出即销毁会话并清 Cookie | `internal/httpapi/auth.go` |
| 页面 | 登录页 + 临时工作台（展示身份与可执行动作，D-11 替换为正式页面） | `internal/httpapi/templates/` |
| 仓储 | `GetUser`、`ListStudents`、`GetAssignment`、`ListAssignmentsByClass` + 快照取值方法 | `internal/store/{users,assignments,models}.go` |

写接口（提交/批阅/补交/催交）当前只做权限校验，通过权限后返回 **501 `not_implemented`**，便于区分"无权(403)"与"未实现(501)"；业务逻辑分别在 D-05/D-07/D-09/D-10 补齐。

真实进程冒烟（`PORT=18081`，独立库 `data/smoke_d03.db`，curl 带 Cookie 文件）：

```
[未登录 /api/me]            HTTP 401 {"code":"unauthenticated",...}
[错误口令登录]              HTTP 401 页面提示: 账号或口令不正确
[S01 登录]                  HTTP 303
[S01 /api/me 并篡改参数]     HTTP 200 {"class_id":"P01","id":"S01","name":"...","permissions":["view_assignment","submit","view_student"],"role":"student"}
[GET 不存在的作业]           HTTP 404 {"code":"not_found",...}
[退出登录]                  HTTP 303
[退出后 /api/me]            HTTP 401
```

说明：Windows 控制台按 GBK 解码 UTF-8 响应会显示乱码，测试断言的是 JSON 字段值而非控制台文本；接口实际返回为标准 UTF-8。

## 3. 过程中发现并修正的问题

1. **草稿泄露**：初版 `GET /api/assignments/{id}` 把草稿返回给了学生。冒烟测试前自查发现（对应假设 AS-09"草稿仅教师可见"），补了可见性分支与两条断言（学生 404 / 教师 200）。
2. **测试期望写错**：`外班访问本班作业也应 404` 用了 P02 的作业 HW2，实际应 200。改为"P01 作业 404 + P02 已发布作业 200"的对照断言，避免把"跨班 404"误测成"所有作业都看不到"。
3. 临时提交消息文件 `.git-commit-msg.txt` 曾被误提交，已 `git rm --cached` 并加入 `.gitignore`（提交 `90a4144`）。
