## 3. 测试覆盖的关键约束

| 测试 | 覆盖的规则 |
| --- | --- |
| `TestMigrateIsIdempotent` | 迁移重复执行不重复建表、只登记 1 条版本 |
| `TestSeedIsIdempotentAndSeedsExpectedData` | 重复种子不重复插账号；8 账号 / 2 班级 / P01 五名学生；口令可校验 |
| `TestUniqueRequestIDPerStudentAssignment` | 同 `request_id` 不能产生第二个版本（幂等的数据层兜底） |
| `TestUniquePointsLedger` | 同学生同作业同原因只能有一条积分流水（防重复发奖） |
| `TestTxRollbackOnError` | 事务失败整体回滚，无脏数据 |
| `TestLoadInvalidOffset` | 非法时钟偏移启动即报错，不带病运行 |

## 5. 数据库选择说明（对应场景 §1.10）

SQLite（纯 Go 驱动）：单实例教学环境足够、零外部依赖、重启可查；并发正确性由状态行乐观锁与唯一约束保证，而非依赖数据库锁语义；仓储层隔离在 `internal/store`，可替换 PostgreSQL。详见仓库 `README.md`。
